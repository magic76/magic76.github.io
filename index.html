GOOD TO KNOW / 03

常見問題

使用 Koolo 需要先建立帳號嗎？

可以直接開始免費文字聊天及語音試用，不需要自行申請 API Key；部分進階功能可能需要額外設定。

Gemini API Key 是免費的嗎？

Google AI Studio 可建立 API Key，但可用的免費額度因模型與用量而異，使用付費方案可能產生費用。
