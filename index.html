GET STARTED / 02

開始使用，比想像中簡單

從想法到實際體驗，依自己的步調開始。

  1. 01

    挑選感興趣的功能

    從 Teacher、Story 或 Fortune 選擇自己的入口。

  2. 02

    設定 Gemini API Key

    有 Google 帳號即可前往 Google AI Studio 建立 API Key，免費配額與費率依 Google 公告。

  3. 03

    直接在瀏覽器體驗

    設定完成後即可使用對應功能；介面語言與對話學習語言分開管理。

GOOD TO KNOW / 03

常見問題

使用 Koolo 需要先建立帳號嗎？

Web 版可直接進入體驗頁面。使用 Gemini 功能前，需要先設定自己的 API Key。

Gemini API Key 是免費的嗎？

Google AI Studio 可建立 API Key，但可用的免費額度因模型與用量而異，使用付費方案可能產生費用。
